---
title: "Get Started with anymd in Under a Minute"
sidebarTitle: "Quickstart"
description: "Add anymd to Claude Code, Cursor, VS Code, or any MCP client in one command, and convert your first document to Markdown immediately."
---

Getting anymd running takes a single command. One `npx` invocation registers the server with every MCP client on your machine at the same time, so your agents can read documents immediately — no API key, no account, no configuration file to hunt down.

<Steps>
  <Step title="Run the setup command">
    Open your terminal and run:

    ```bash
    npx -y @sylphx/anymd setup
    ```

    This one command adds anymd to **all** MCP clients it finds on your machine at once: Claude Code, Codex, Cursor, VS Code, Claude Desktop, Windsurf, and Gemini CLI. It is safe to run again — existing entries are updated, not duplicated.

    <Tip>
      Pass `--dry-run` to preview exactly what will be written before any file is
      touched, or `--remove` to undo all registrations cleanly.
    </Tip>
  </Step>

  <Step title="Ask your agent a document question">
    Open any registered agent (Claude Code, Cursor, etc.) and ask something that
    requires a real document. For example:

    > Summarize the results table in `papers/attention.pdf` and cite the page.

    The agent calls the `read` tool and gets back Markdown with `<!-- page N -->`
    anchors embedded — so it can cite the exact page in its answer. For a folder
    full of files, it calls `search` first to locate the right document before
    reading it.
  </Step>

  <Step title="Try the CLI">
    The same binary works directly from your terminal — no agent needed. Convert
    a document to Markdown and write it to a file:

    ```bash
    anymd report.pdf > report.md
    ```

    Or search for a term across every PDF in a folder:

    ```bash
    anymd search "indemnification" contracts/
    ```

    Run `anymd` with no arguments to see the full list of options, or check the
    [CLI reference](/cli/commands) for every flag.
  </Step>
</Steps>

<Tip>
  Run `anymd doctor` after setup to see which optional tools anymd found on your
  machine — such as tesseract for OCR and ffmpeg for audio and video transcripts.
  The output lists exactly what is available and what to install if you need a
  specific format.
</Tip>
