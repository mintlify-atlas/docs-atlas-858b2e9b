anymd is local-first by design. Documents never leave your machine unless you explicitly pass a URL — and even then only that specific URL is fetched. No account, API key, or cloud service is involved in any conversion.

## Local-first

anymd runs entirely on your machine. There is no account to create, no API key to manage, and nothing is uploaded anywhere. All parsing, OCR, and Markdown rendering happen in the local native binary. The only outbound network traffic anymd initiates is a URL fetch you explicitly request.

## URL fetch guards

When `read` or `search` is given a URL, anymd applies several protections before and during the download:

- **Private address blocking** — Private, loopback, and link-local addresses are refused, preventing a prompt from pointing anymd at your router, cloud metadata endpoint (e.g., `169.254.169.254`), or local services.
- **DNS rebinding protection** — Every redirect hop is checked and pinned to the address it resolved to, so a DNS rebinding attack cannot swap in a private address between the check and the actual connection.
- **Download size cap** — Downloads are capped at 256 MB.

## Confine file access

By default the server can read any file your user account can access. To limit it to specific folders, use `--allow-dir` (repeatable) or set the `MCP_PDF_ALLOWED_DIRS` environment variable:

```bash
claude mcp add anymd -- npx -y @sylphx/anymd --allow-dir=$HOME/docs --allow-dir=$HOME/papers
```

```json
{
  "command": "npx",
  "args": ["-y", "@sylphx/anymd"],
  "env": { "MCP_PDF_ALLOWED_DIRS": "/home/me/docs" }
}
```

Paths outside the allowed directories are refused — including paths reached through symlinks that point outside the allowed directories.

## HTTP transport

stdio is the default transport. Set `MCP_TRANSPORT=http` to serve MCP over HTTP on `MCP_HTTP_HOST:MCP_HTTP_PORT` (default `127.0.0.1:8080`).

- Set `MCP_API_KEY` and every `/mcp` request must include a matching `X-API-Key` header, or it receives a `401` response.
- `/mcp/health` remains open without authentication.
- The server refuses a non-loopback bind address unless a key is configured — you cannot accidentally expose the server on a network interface without also setting an API key.
- `MCP_CORS_ORIGIN` sets an explicit allowed CORS origin for browser-based clients.

## External tools

`tesseract`, `ffprobe`, `ffmpeg`, and the optional ForcedAligner helper are optional external programs. When anymd uses them, it runs each one directly — without a shell — with a timeout and an output cap. Nothing from a document's content is ever interpreted as a command.

## Parsing untrusted files

Every format is parsed in Rust. PDF pages are processed in isolation, so one malformed or adversarial page cannot take down the whole document. Resource limits bound page count, rendered pixels, and output size, preventing runaway processing on crafted inputs.
