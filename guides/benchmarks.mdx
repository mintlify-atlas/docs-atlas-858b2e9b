**AgentDocBench** is an open, reproducible benchmark designed specifically for the "document → Markdown for agents" task. It measures what an AI agent actually needs from a converter: words verbatim, in reading order, tables intact, fast, and in as few tokens as possible. The benchmark runs anymd, Docling, Marker, MarkItDown, Kreuzberg, Unstructured, and pdftotext on the same license-clean documents on GitHub-hosted runners. The scoring is blind to which tool produced each output, the corpus and ground truth are public, and every category where anymd loses is listed in the tables below.

## Methodology

AgentDocBench uses 38 documents across 12 categories on GitHub-hosted Linux x86_64 runners with 4 CPUs and a standard set of system packages (poppler, tesseract with Chinese and Japanese, pandoc). Every document in the corpus is public domain, CC0, CC BY, CC BY-SA, MIT-licensed, or under an open government license, and is pinned by SHA-256.

Every output is normalized the same way — Unicode NFKC, Markdown and HTML markup removed, whitespace collapsed, curly quotes straightened, spaces between CJK characters dropped — and compared against the document's ground truth on four metrics:

- **Sentences** — key sentences copied verbatim from the document must appear verbatim. Glued words, split columns, or dropped lines fail the sentence.
- **Text F1** — bag-of-words F1 against a reference text. Recall drops when text is lost; precision drops when noise is added.
- **Reading order** — headings and passage openings must appear in order. The score is the longest in-order chain divided by the number of strings.
- **Table cells F1** — every ground-truth table row is matched to the output row with the longest in-order run of equal cells. Pipe tables and HTML tables both count; plain text scores 0.

**Document score** is the mean of the metrics that apply; **category score** is the mean over its documents (failed, timed-out, or unsupported counts as 0); **overall** is the mean of the category scores. Time is wall time of a fresh process per file (start-up included), median of 3 runs after one untimed warm-up. Tokens are `o200k_base`.

## Reproduce it

The `bench/` directory in the repository contains the full benchmark harness, corpus manifest, ground truth, raw results, and per-tool adapters. Visit the repository to run it yourself:

[**github.com/SylphxAI/anymd/tree/main/bench**](https://github.com/SylphxAI/anymd/tree/main/bench)

The [Benchmark workflow](https://github.com/SylphxAI/anymd/actions/workflows/benchmark.yml) runs every tool on its own GitHub-hosted runner with the same system packages, and publishes merged results and every Markdown output as an artifact.

<Note>
**Image OCR and video benchmarks use separate datasets.**

On **OmniDocBench v1.6** (1,651 page images, CVPR 2025), anymd scores **21.4** overall using `tesseract` with its default English model and no layout, table, or formula model. Vision-language models trained specifically for this task score in the 95–97 range by comparison.

For **embedded video subtitles**, anymd achieves **91.7% recall (11/12 cues)** on both MP4 mov\_text and Matroska SubRip fixture sets (4 clips / 12 cues each). Direct FFmpeg retains all 12 cues; anymd's rolling-caption deduplication drops one repeated caption at a different timestamp. These are small regression fixtures, not representative film or lecture datasets.

Both benchmarks are reproducible from the repository. See [`bench/omnidocbench`](https://github.com/SylphxAI/anymd/tree/main/bench/omnidocbench) and [`bench/media`](https://github.com/SylphxAI/anymd/tree/main/bench/media).
</Note>
