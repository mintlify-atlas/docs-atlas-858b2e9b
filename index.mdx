anymd is a fast Rust MCP server and CLI that turns any document into clean Markdown your AI agent can read. It runs entirely on your machine — no API key, no cloud upload, no external service. One command adds it to every MCP client you use.

```bash
npx -y @sylphx/anymd setup              # add to Claude Code, Cursor, VS Code, Codex, and more
npx -y @sylphx/anymd report.pdf         # or convert from the shell
```

## Get started in three steps

<Steps>
  <Step title="Install anymd">
    Run the setup command to add anymd to every MCP client on your machine:

    ```bash
    npx -y @sylphx/anymd setup
    ```

    Prefer Python or Docker? See [Installation](/installation) for all options.
  </Step>
  <Step title="Ask your agent about a document">
    Open Claude Code, Cursor, or any configured client and ask:

    > Summarize the results table in `papers/attention.pdf` and cite the page.

    The agent calls the `read` tool, receives Markdown with `<!-- page N -->` anchors, and cites the source.
  </Step>
  <Step title="Convert from the terminal">
    anymd is also a fast CLI converter:

    ```bash
    anymd report.pdf > report.md
    anymd search "indemnification" contracts/ --glob '*.pdf'
    anymd doctor   # check which optional tools are available
    ```
  </Step>
</Steps>
