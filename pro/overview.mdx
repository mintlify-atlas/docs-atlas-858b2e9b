**anymd Pro** adds two capabilities to the free anymd MCP server and CLI: verifiable video timelines with exact decoded frames, and cite-check, which confirms that a quoted passage occurs in a PDF at the stated page and bounding box. Both run entirely on your machine. Pro is aimed at agents and people who need to point at a source and be believed — legal review, research, finance, and media work.

<Note>
  The anymd core remains MIT licensed and completely free. Reading, outlining, searching, and inspecting documents, OCR, transcripts, the MCP server, and the CLI are all free and ungated. Nothing that was free has moved to Pro. Ordinary `read` and `outline` of video (metadata, chapters, subtitles) are still free.
</Note>

## What Pro adds

<CardGroup cols={2}>
  <Card title="Video Timelines" icon="film" href="/pro/video-timeline">
    A bounded, hashed video timeline with FFmpeg-detected scenes and subtitle cues, plus `render_frame` for exact decoded frames with SHA-256 — so a citation like "at 01:17 the slide shows X" can be re-checked.
  </Card>
  <Card title="Cite-Check" icon="circle-check" href="/pro/cite-check">
    `cite_check` takes a PDF and a list of citations — quote, page, and bounding box — and returns a verdict for each: `verified_exact`, `verified_normalized`, `unmatched`, or `insufficient_evidence`.
  </Card>
</CardGroup>

## Activate

Run once after purchase to save your licence on the machine:

```bash
anymd pro activate '<your token>'
anymd pro status
```

Or supply the token through an environment variable instead:

```bash
export ANYMD_PRO_TOKEN='<your token>'
```

The environment variable wins over the saved licence file when both are present. `anymd pro status` shows whether Pro is active and which version is running — it never prints the token.
