anymd is a fast, local Rust binary that converts any document — PDF, Word, PowerPoint, Excel, EPUB, HTML, images, audio, and video — into clean Markdown that AI agents can read, cite, and reason over. It runs entirely on your machine with no API key and no account. Developers reach for anymd when they want their agents to work directly with real documents: research papers, financial reports, slide decks, contracts, and entire folder trees, all through a single MCP tool call or one shell command.

## Two modes, one binary

**MCP server** — the primary mode for AI agents. When an MCP client such as Claude Code, Cursor, or VS Code starts anymd, it exposes four tools: `read`, `search`, `outline`, and `inspect`. Agents call `read` to convert a document and get back paginated Markdown with `<!-- page N -->` citation anchors, or `search` to find text across an entire folder of mixed formats. The server runs over stdio with no network service to configure.

**CLI** — the same binary doubles as a command-line converter. Pipe a file in and Markdown comes out. It accepts multiple files at once, reads from stdin, fetches web URLs, and supports every option available to the MCP tools. No agent required — just your terminal.
