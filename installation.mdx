The fastest path to anymd is **npm**: Node 18+ is the only prerequisite, and the `npx` one-liner requires nothing installed globally at all. If you prefer Python, Docker, or building from source, every method ships the same prebuilt native binary — or compiles one on your machine when you use Cargo.

## Install anymd

<Tabs>
  <Tab title="npm">
    Run anymd once without a global install using `npx`:

    ```bash
    npx -y @sylphx/anymd
    ```

    Or install it globally so the `anymd` command is always on your `PATH`:

    ```bash
    npm install -g @sylphx/anymd
    ```

    Node 18 or newer is the only requirement. npm automatically downloads the
    prebuilt native binary for your platform (macOS, Linux, Windows — x64 and
    arm64).
  </Tab>
  <Tab title="Python">
    Run anymd once with `uvx` (no install needed if you have
    [uv](https://docs.astral.sh/uv/)):

    ```bash
    uvx anymd report.pdf > report.md
    ```

    Start the MCP server via `uvx`:

    ```bash
    uvx anymd mcp
    ```

    Or install permanently with pip:

    ```bash
    pip install anymd
    ```

    The Python wheels carry the same prebuilt native binary as the npm package —
    no compilation required.
  </Tab>
  <Tab title="Docker">
    Convert a file in your current directory (mounts `$PWD` as `/data` inside
    the container):

    ```bash
    docker run --rm -v "$PWD:/data" ghcr.io/sylphxai/anymd report.pdf > report.md
    ```

    Run as an MCP server over stdio (for clients that accept a Docker command):

    ```bash
    docker run -i --rm ghcr.io/sylphxai/anymd
    ```

    Images are published for **amd64** and **arm64** and use glibc 2.17 or newer.
  </Tab>
  <Tab title="Cargo">
    Build and install from [crates.io](https://crates.io/crates/anymd):

    ```bash
    cargo install anymd
    ```

    Requirements: **Rust 1.95+**, CMake, and a C++ compiler. The Cargo build
    includes bundled ASR and compiles the same binary as the prebuilt releases.
    Local doc-VLM OCR is a separate engine; run `anymd setup ocr` after install
    to download it, or build with `--features ocr-vlm` to link it in directly.

    <Note>
      The npm, pip, and Docker packages ship a prebuilt binary. `cargo install`
      compiles the binary on your machine, which takes longer but gives you full
      control over the build.
    </Note>
  </Tab>
</Tabs>

## Add to a specific MCP client

If you want to register anymd with one client by hand instead of running
`npx -y @sylphx/anymd setup`, use the snippet for your client below.

**Claude Code**

```bash
claude mcp add anymd -- npx -y @sylphx/anymd
```

**Codex**

```bash
codex mcp add anymd -- npx -y @sylphx/anymd
```

Or add it to `~/.codex/config.toml`:

```toml
[mcp_servers.anymd]
command = "npx"
args = ["-y", "@sylphx/anymd"]
```

**Cursor**

Add to `.cursor/mcp.json`:

```json
{ "mcpServers": { "anymd": { "command": "npx", "args": ["-y", "@sylphx/anymd"] } } }
```

**VS Code**

From the terminal:

```bash
code --add-mcp '{"name":"anymd","command":"npx","args":["-y","@sylphx/anymd"]}'
```

Or add to `.vscode/mcp.json`:

```json
{ "servers": { "anymd": { "type": "stdio", "command": "npx", "args": ["-y", "@sylphx/anymd"] } } }
```

**Claude Desktop**

Add to `claude_desktop_config.json` (Settings → Developer → Edit Config):

```json
{ "mcpServers": { "anymd": { "command": "npx", "args": ["-y", "@sylphx/anymd"] } } }
```

**Windsurf, Zed, Cline, and other clients**

Any client that speaks MCP over stdio accepts: command `npx`, args `["-y", "@sylphx/anymd"]`.

To restrict the server to a specific directory, add `--allow-dir`:

```json
{ "command": "npx", "args": ["-y", "@sylphx/anymd", "--allow-dir=/path/to/docs"] }
```

## Check optional tools

After installing, run `anymd doctor` to see which optional tools anymd found on your machine — tesseract for OCR, ffmpeg and ffprobe for audio and video. The output lists exactly what is available and what to install if you need a specific format.

```bash
anymd doctor
```

## Verify a download

Every release asset — `.tar.gz` and `.zip` binaries and `.mcpb` bundles — is listed in `SHA256SUMS` and carries a signed [GitHub artifact attestation](https://docs.github.com/en/actions/security-for-github-actions/using-artifact-attestations/using-artifact-attestations-to-establish-provenance-for-builds) that names the exact workflow run that built it. Each release also attaches a CycloneDX software bill of materials (`anymd-<version>.cdx.json`).

Download the asset and `SHA256SUMS` from the [latest release](https://github.com/SylphxAI/anymd/releases/latest), then verify:

```bash
# Verify checksum (macOS: replace sha256sum with shasum -a 256)
sha256sum -c SHA256SUMS --ignore-missing

# Verify the GitHub artifact attestation
gh attestation verify anymd-darwin-arm64.tar.gz --repo SylphxAI/anymd
```

<Note>
  The Linux wheels and the Docker image require **glibc 2.17 or newer**. Alpine
  Linux and other musl-based distributions are not supported by the prebuilt
  binary. On Alpine, build from source instead:

  ```bash
  cargo install anymd
  ```
</Note>
